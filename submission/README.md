# Cognifyz Data Analysis Internship — Level 1 & Level 2

Data analysis of a Zomato-style restaurant dataset (9,551 restaurants) covering cuisine trends, city-wise performance, pricing, online delivery impact, rating distribution, cuisine combinations, geographic spread, and restaurant chains.

## Tasks Completed

**Level 1**
1. Top Cuisines
2. City Analysis
3. Price Range Distribution
4. Online Delivery Impact

**Level 2**
1. Restaurant Ratings Distribution
2. Cuisine Combinations
3. Geographic Analysis
4. Restaurant Chains

## Tools Used
- Python 3
- pandas
- matplotlib

## How to Run
```bash
pip install pandas matplotlib
python analysis.py
```

## Key Findings
See [results.md](results.md) for the full breakdown, including:
- North Indian is the most common cuisine (41.5% of restaurants)
- New Delhi has the highest restaurant count (5,473)
- Restaurants offering online delivery have a notably higher average rating (3.25 vs 2.47)
- Barbeque Nation has the highest average rating among major restaurant chains (4.35)
